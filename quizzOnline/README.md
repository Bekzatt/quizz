# Білім жарысы — онлайн-версия (Firebase)

Игра работает через интернет: учитель открывает экран учителя на любом устройстве (компьютер, телефон, проектор), ученики заходят с телефонов по QR-коду или 4-значному коду комнаты. Компьютер-сервер и `start.bat` не нужны.

```
quizzOnline/
├─ public/jarys/index.html ← игра «Білім жарысы» (всё в одном файле)
├─ public/index.html      ← главная: «Білім ойындары» (6 игр; открывается и двойным кликом)
├─ public/questions.js    ← встроенные вопросы (40 по информатике) — общие для всех игр
├─ public/sets.js         ← готовые наборы вопросов по предметам и классам
├─ public/fb.js           ← подключение Firebase, вход через Google, счётчики посещений
├─ public/img/            ← картинки для «Батырлар шайқасы»
├─ database.rules.json    ← правила безопасности базы
├─ firebase.json          ← настройки хостинга
└─ .firebaserc            ← ID проекта Firebase
```

Игры уже работают: **https://bilim-jarysy.web.app** (проект `informatika-jarysy`). Главная страница — меню «Білім ойындары» (6 игр), шестая карточка «Білім жарысы» открывает эту игру (`/jarys/`). Раздел ниже нужен, только если разворачиваете свою копию в другом Google-аккаунте.

---

## Своя копия с нуля (~15 минут)

### 1. Создать проект Firebase
1. Откройте https://console.firebase.google.com и войдите своим Google-аккаунтом.
2. **«Создать проект»** → имя, например `informatika-jarysy` → Google Analytics можно **выключить** → «Создать».
3. Запомните **ID проекта** (под названием, например `informatika-jarysy-1a2b3`).

### 2. Создать базу данных
1. Слева: **Build → Realtime Database → Create Database**.
2. Регион: **europe-west1 (Belgium)** — ближе всего к Казахстану.
3. Режим: **Start in locked mode** (наши правила загрузятся при деплое).

### 3. Включить анонимный вход
1. Слева: **Build → Authentication → Get started**.
2. Вкладка **Sign-in method** → **Anonymous** → **Enable** → Save.

> Без этого шага игра покажет «Firebase-те «Anonymous» кіру қосылмаған».

### 3а. Включить вход через Google (для сохранения вопросов учителя)
1. **Build → Authentication → Sign-in method → Add new provider → Google → Enable**, выбрать «Support email» (ваш адрес) → Save.
2. **Authentication → Settings → Authorized domains**: должен быть адрес сайта (`bilim-jarysy.web.app` или `ВАШ-ID.web.app`). Если его нет — «Add domain».

> Без этого кнопка «Google арқылы кіру» покажет «Google арқылы кіру Firebase-те әлі қосылмаған». Играть можно и без входа.

### 4. Указать свой проект
- В `.firebaserc` замените `informatika-jarysy` на ID из шага 1.
- В `firebase.json` уберите строку `"site": "bilim-jarysy",` — это имя занято нашим сайтом. Без неё игра загрузится на `https://ВАШ-ID.web.app`.

### 5. Загрузить игру в интернет
Нужен Node.js. В PowerShell (версия 13 работает с Java 11; для эмулятора в v14+ нужна Java 21):

```bash
npm install -g firebase-tools@13
```

```bash
firebase login
```

```bash
cd путь\к\папке\quizzOnline
```

```bash
firebase deploy
```

В конце будет ссылка вида **`https://ВАШ-ID.web.app`** — это адрес игры.

Обновить наш сайт после изменений: из папки `quizzOnline` выполнить `firebase deploy`. Старый адрес informatika-jarysy.web.app выключен.

## Как играть на уроке

1. **Учитель**: открыть сайт → карточка **«Білім жарысы»** → **Онлайн** → **Мұғалім: бөлме ашу**. Появятся QR-код и код комнаты (например `4821`). Можно вывести на проектор (кнопка «⛶ Толық экран»).
2. **Ученики**: сканируют QR-код камерой телефона (или открывают сайт → «Білім жарысы» → «Оқушы: кодпен кіру» → вводят код) → пишут имя → «Қосылу».
3. Учитель выбирает время, при желании добавляет свои вопросы, жмёт **«Ойынды бастау»**.
4. Во время игры у учителя живой рейтинг, в конце — пьедестал. «Қайта бастау» — новая игра с теми же учениками.

Экран учителя запоминает комнату: если обновить страницу, откроется та же комната. «Жаңа бөлме» — новый код. **«Бөлмені жабу»** — закончить урок: комната удаляется из базы, ученики видят «Мұғалім бөлмені жапты».

Если просто закрыть вкладку, ученики увидят «Мұғалім экраны жабық». Комната, где учителя нет больше 2 часов, удаляется автоматически, когда кто-нибудь откроет экран учителя.

## Изменения в игре
Встроенные вопросы для **всех** игр — в одном файле `public/questions.js` (строка: `Сұрақ | Дұрыс | Қате | Қате`). Игра «Білім жарысы» — `public/jarys/index.html`; меню и мини-игры «Білім ойындары» — в `public/index.html` (его можно открыть и двойным кликом, без интернета). Загрузите снова:

```bash
firebase deploy --only hosting
```

## Безопасность
- Начать, остановить игру и удалить ученика может только тот, кто создал комнату (его браузер).
- Ученик может менять только свои данные. База проверяет каждое поле: имя до 20 символов, аватар без HTML, цвет `#RRGGBB`, очки — числа (максимум 5000). Лишние поля запрещены.
- Всё, что приходит от учеников, дополнительно экранируется перед показом на экране.
- Войти можно только в существующую комнату.
- «✕» у ученика: **Шығару** — может зайти снова; **Бұғаттау** — не может войти в эту комнату, пока учитель не нажмёт «↩ Қайтару». Блокировка привязана к браузеру ученика: из режима инкогнито или другого браузера он зайдёт как новый ученик.
- **«🔒 Бөлмені құлыптау»** (под кодом комнаты): когда все свои вошли, закройте вход. Новые ученики, в том числе из инкогнито, войти не смогут («Бөлме құлыпталған»). Кто уже в комнате, продолжает играть, после обновления страницы тоже. «🔓 Бөлмені ашу» снова открывает вход. Ученик, которого удалили «✕» или «Қайта бастау» (офлайн), в закрытую комнату не вернётся, пока её не откроют.
- Комнаты старше 12 часов можно использовать заново, поэтому коды не заканчиваются. «＋ Жаңа бөлме» удаляет прежнюю комнату учителя.

## Готовые наборы вопросов
На главной — раздел **«Дайын жинақтар»**: предметы (Информатика, Қазақ тілі, Математика, Қазақстан тарихы) и наборы по классам/темам, например «7 сынып · Python негіздері», «Хабарлы сөйлем». Отметьте один или несколько наборов — все 6 игр (и «Білім жарысы» онлайн) берут вопросы из них плюс ваши свои вопросы. Ничего не отмечено — 40 встроенных вопросов по информатике. «Көру» показывает вопросы набора с ответами. Классы указаны примерно — сверяйте со своим КТП/ҚМЖ. Новые наборы добавляются в `public/sets.js` (формат тот же: `Сұрақ | Дұрыс | Қате | Қате`).

## Вход для учителя (сохранение вопросов)
Кнопка с человечком вверху справа или блок в разделе «Сұрақтар» → **«Google арқылы кіру»**. После входа свои вопросы, «Тек өз сұрақтарым» и выбранные наборы сохраняются в аккаунте: на другом компьютере достаточно войти — всё появится. Если до входа в браузере уже были вопросы, они объединяются с сохранёнными (без повторов). **«Шығу»** — вопросы остаются в аккаунте, а с этого компьютера удаляются (удобно для общего компьютера в классе). Вход не обязателен: без него всё работает как раньше, вопросы хранятся только в этом браузере. Данные учителя (`users/{uid}`) может читать и менять только он сам.

## Статистика сайта
Без cookies и без личных данных — только счётчики по дням. Смотреть: **Firebase Console → Realtime Database → `stats` → дата**:
- `visit` — посетители главной (один браузер считается раз в день);
- `g_battle`, `g_tug`, `g_balloons`, `g_memory`, `g_wheel` — сколько раз запускали каждую игру;
- `local` — «Білім жарысы» на одном экране, `room` — открыто комнат учителя, `online` — запущено онлайн-игр, `join` — учеников вошло в комнаты;
- `login` — входов через Google.

## Свои вопросы
Свои вопросы добавляются **в одном месте — на главной странице**, раздел «Сұрақтар» (внизу меню): форма (сұрақ, дұрыс жауап, 1–2 қате жауап) → «Сұрақ қосу». Они сразу появляются во всех 6 играх, включая «Білім жарысы» онлайн. В «Білім жарысы» показано только количество вопросов и кнопка «Өзгерту», которая открывает эту форму (с экрана учителя — в новой вкладке, комната не закрывается). Вопросы можно править (✎) и удалять (🗑). Много вопросов сразу — «Көп сұрақты мәтінмен қою»: строки `Сұрақ | Дұрыс | Қате | Қате` или столбцы, скопированные из Excel/Word-таблицы.

## Ссылка для учеников
Под QR-кодом — полная ссылка на комнату и кнопка «📋 Көшіру»: её можно отправить в WhatsApp/Telegram, ученик откроет её и сразу попадёт в комнату.

## Бесплатные лимиты (тариф Spark)
- **100 одновременных подключений** — примерно 3 класса по 30 человек одновременно.
- 10 ГБ трафика в месяц — хватает на сотни игр.
- Если понадобится больше — тариф Blaze (оплата по факту, для школы обычно копейки).

## Проверка без интернета (для разработчика)
```bash
firebase emulators:start --project demo-inform --only auth,database,hosting
```
Откройте http://127.0.0.1:5000/jarys/?host — игра сама подключится к эмуляторам.
